# Support

Use [GitHub Discussions](https://github.com/TimoSchoenberger/passport-photo-printer/discussions)
for setup questions and [GitHub Issues](https://github.com/TimoSchoenberger/passport-photo-printer/issues)
for reproducible bugs or focused feature requests.

For security issues, follow [SECURITY.md](SECURITY.md) and do not post details
publicly. This is a community-maintained project with no guaranteed response
time or commercial support.
